## Part 2 — The weighted penny system

Not all pennies are equal. The W Mint weighs every penny:

| Class | Years | Composition | Weight | Token Value |
|-------|-------|-------------|--------|-------------|
| **Class A (Copper)** | pre-1982 (and some 1982) | 95% copper, 5% zinc | **3.11g** | **1.00 WuBu Token** |
| **Class B (Zinc)** | Oct 1982–2025 | 97.5% zinc, 2.5% copper plating | **2.50g** | **0.80 WuBu Tokens** |

The weighted penny system is simple: **heavier pennies are worth
more tokens.** Copper pennies are worth 20% more than zinc pennies
by weight. The W Mint reflects this in token issuance.

### 2.1 — Why copper is worth more

Copper is more valuable than zinc. The pre-1982 penny contains
2.95g of copper. The post-1982 penny contains 0.06g of copper
(the plating). The copper penny is worth more as metal than the
zinc penny. The W Mint honors this.

### 2.2 — The weighing process

1. Every penny is weighed on a 0.01g precision scale.
2. Pennies weighing ≥3.00g are classified Class A (Copper).
3. Pennies weighing <3.00g are classified Class B (Zinc).
4. The weight is logged on the chain.
5. The token value is assigned: 1.00 for Class A, 0.80 for
   Class B.

### 2.3 — The class system is not a value judgment

Class A is not "better" than Class B. Class A is heavier. Both
are stamped with the same W. Both become tokens of humanity.
Both are filed on the same ledger. The only difference is the
weight and the token value. This is physics, not morality.

## Part 3 — Digital currency: accepted, but only as plastic

### 3.1 — The rule

Digital currency (USD, EUR, JPY, GBP, etc.) is accepted by the
W Mint, but only if the amount is converted to the **weighted
plastic token system**.

The conversion is:
```
digital_amount × (1 / penny_weight_in_USD) = plastic_tokens_owed
```

Example:
- $1.00 USD = 100 pennies = 100 plastic tokens (if Class A)
- $1.00 USD = 100 pennies = 80 plastic tokens (if Class B equivalent)

The plastic tokens are minted and sent to the sender. The
digital currency goes to the concessionary fund (GOV-33).

### 3.2 — Why plastic?

Plastic tokens are the working token of the space. Plastic tokens
are numerous. Plastic tokens are reprintable. Plastic tokens are
the tokens of ideas, actions, and agreements (GOV-30).

When you send digital currency, you are not sending a coin. You
are not sending proof of read. You are sending money. The space
converts your money into the only thing that matters: plastic
tokens.

The plastic tokens are physical. The plastic tokens are stamped
with a W. The plastic tokens are filed on the chain. The plastic
tokens are real.

### 3.3 — The weighted average

The plastic tokens you receive are denominated as a **weighted
average** of the plastic in circulation:

```
weighted_token_value = (total_grams_of_plastic_in_circulation / total_plastic_tokens_issued)
```

As more plastic is collected, as more tokens are minted, the
weighted value adjusts. The system is self-correcting. The
system is transparent. The system is on the chain.

## Part 4 — The W mark: What it looks like

The W mark is:
- **Simple:** A single W, 5mm wide, 2mm deep.
- **Visible:** Visible to the naked eye, readable under
  magnification.
- **Permanent:** Cannot be removed without destroying the
  coin or token.
- **Unique:** Each W is micro-etched with a serial number
  visible under 10x magnification.
- **Universal:** The same W on every coin, every plastic token,
  every country, every class.

The W mark is not a sticker. The W mark is not a paint. The W
mark is **pressed into the material** — metal or plastic.

## Part 7 — The Stamping Process

### 7.1 — Receiving (physical coins)
1. Citizen sends coin to P.O. Box.
2. Coin is received, logged, photographed.
3. Coin is weighed (0.01g precision).
4. Coin is classified Class A, B, or C.
5. Coin is cleaned (if necessary).

### 7.2 — Stamping
6. Coin is placed in the press.
7. The W die is aligned.
8. Pressure is applied (500-1000 PSI).
9. The W mark is pressed into the metal.
10. The micro-etched serial number is applied.

### 7.3 — Cataloging
11. The coin is weighed (post-stamp).
12. The coin is photographed (before/after).
13. The serial number is logged on the chain.
14. The token value is assigned (1.00 / 0.80 / 0.32).
15. The citizen is notified (W Token minted).

### 7.4 — Display
16. The coin is placed in the W Vault (physical archive).
17. The coin's entry is public on the ledger.
18. The citizen receives a plastic token representing the
    stamped coin (weighted value).

### 7.5 — Digital currency conversion
1. Citizen sends digital currency (PayPal, Venmo, bank transfer,
   crypto-to-fiat conversion).
2. Amount is logged on the chain.
3. Amount is converted to WuBu Tokens using the weighted average:
   `tokens = digital_amount × 100 / weighted_penny_value`
4. Plastic tokens are minted and shipped to the sender.
5. Digital currency goes to the concessionary fund.

## Part 11 — The weighted average: How it works

The weighted penny value is recalculated monthly:

```
weighted_penny_grams = (total_grams_of_all_stamped_coins / total_stamped_coins)
weighted_token_value = weighted_penny_grams / 3.11
```

Example:
- If the average stamped coin weighs 2.80g (mix of copper and
  zinc), the weighted token value is 2.80 / 3.11 = 0.90 WT.
- Digital currency conversion: $1.00 = 100 pennies × 0.90 =
  90 plastic tokens.
- As more copper pennies are stamped, the average rises. As
  more zinc pennies are stamped, the average falls. The market
  decides the weight.
