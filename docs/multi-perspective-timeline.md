## Part 2 — The four perspectives

Every event in the space's timeline records:

1. **The victor's perspective.** What the winners say happened.
2. **The vanquished's perspective.** What the losers say happened.
3. **The bystander's perspective.** What neutral observers say happened.
4. **The future archaeologist's perspective.** What evidence says happened.

Example — The founding of the space:
- Victor: "We built a cooperative government."
- Vanquished: "We were excluded from the founding."
- Bystander: "A new government was filed."
- Archaeologist: "Filing GOV-1 was the first event on the chain."

All four are filed. All four are public. All four are permanent.

## Part 3 — The anthropological mandate

The space's timeline is not a single narrative. The space's
timeline is a **multi-perspective record** — the same event told
by everyone who experienced it. The user chooses which perspective
to read. The user chooses which perspective to believe.

This is the space's fix for the singular-perspective problem.
